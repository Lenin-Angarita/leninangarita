Sequences and Limits

Fall 2026 · [Date]

Introduction

Analysis begins with a single question: what does it mean for a sequence of numbers to approach a value? Calculus treats this idea informally; here we make it precise, in a form robust enough to build continuity, differentiation, and integration on top of.

Defining convergence

There are two standard, equivalent ways to state the definition. The ε–N form is the one you will use in every proof; the neighborhood form is the one that generalizes to metric and topological spaces later in the course.

Definition 1.1.

Let \((a_n)\) be a sequence of real numbers and let \(L \in \mathbb{R}\). We say that \((a_n)\) converges to \(L\), written \(\lim_{n\to\infty} a_n = L\), if

for every \(\varepsilon > 0\) there exists \(N \in \mathbb{N}\) such that \(n \ge N\) implies \(|a_n - L| < \varepsilon\).

\[ \forall\, \varepsilon>0,\ \exists\, N\in\mathbb{N} : n \ge N \implies |a_n - L| < \varepsilon \]
(1)
Definition 1.1′ (equivalent).

\((a_n)\) converges to \(L\) if every open interval containing \(L\) contains all but finitely many terms of the sequence — that is, all terms from some index onward.

Uniqueness of limits

Theorem 1.2 (Uniqueness of limits).

If a sequence converges, its limit is unique.

Proof

Suppose, for contradiction, that \(a_n \to L_1\) and \(a_n \to L_2\) with \(L_1 \ne L_2\). Set \(\varepsilon = \tfrac{|L_1 - L_2|}{2} > 0\).

By convergence to \(L_1\) there is \(N_1\) with \(|a_n - L_1| < \varepsilon\) for \(n \ge N_1\); by convergence to \(L_2\) there is \(N_2\) with \(|a_n - L_2| < \varepsilon\) for \(n \ge N_2\). Take \(n \ge \max(N_1, N_2)\). By the triangle inequality,

\[ |L_1 - L_2| \le |L_1 - a_n| + |a_n - L_2| < \varepsilon + \varepsilon = |L_1 - L_2|, \]
(2)

a strict inequality \(|L_1-L_2| < |L_1-L_2|\), which is impossible. Hence \(L_1 = L_2\). ∎

Examples

Example 1.3.

The sequence \(a_n = \dfrac{1}{n}\) converges to \(0\).

Given \(\varepsilon > 0\), the Archimedean property gives \(N \in \mathbb{N}\) with \(N > 1/\varepsilon\). Then for all \(n \ge N\),

\[ \left|\frac{1}{n} - 0\right| = \frac{1}{n} \le \frac{1}{N} < \varepsilon. \]
(3)

Algebra of limits

Theorem 1.4 (Algebra of limits).

If \(a_n \to L\) and \(b_n \to M\), then \(a_n + b_n \to L + M\) and \(a_n b_n \to LM\); if additionally \(M \ne 0\), then \(a_n/b_n \to L/M\).

Remark.

Each part is a direct ε–N estimate in the same spirit as Example 1.3, and is left as an exercise. We will use this theorem freely from the next lecture onward, so it is worth writing out at least the sum case yourself.
